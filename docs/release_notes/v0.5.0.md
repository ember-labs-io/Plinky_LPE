### Breaking changes
- The "relative" CV input functionality has been removed to make place for a more common way of processing CV input
- The midi CC number for Latch Toggle was moved from 101 (which is reserved for RPN MSB) to CC 69

### New Features
#### Multi-timbral parameters
Plinky now has 33 per-string multi-timbral parameters. They are:

- The 23 parameters on the upper two rows of pads
- Arp Toggle
- Latch Toggle
- Gate length
- The seven sample parameters: 
    - Scrub(+ Jitter)
    - Grain Size(+ Jitter)
    - Play Speed(+ Jitter)
    - Timestretch

##### Usage
- While holding [FN_SHIFT_A] or [FN_SHIFT_B], a small 'M' next to the parameter name indicates whether this parameter is multi-timbral
- Hold [FN_SHIFT_A] or [FN_SHIFT_B] plus one of these parameters to toggle between mono-timbral and multi-timbral parameter editing
- When multi-timbral editing is active:
    - A small number on screen indicates which string is selected
    - All eight touchstrips will show edit-strips on their leds, the selected strip is brighter than the others
    - Touching an edit-strip or pressing [FN_LEFT] and [FN_RIGHT] will change which string is selected
    - Each per-string value can be modified as usual by sliding on the edit strip and rotation/pressing the encoder

To reset all strings to the same value, toggle back to mono-timbral editing and change the parameter value. This will update the parameter on all strings

*The multi-timbral parameters always operate in multi-timbral mode behind the scenes. Changing the value of a multi-timbral parameter's value in mono-timbral editing mode just sets the parameter to the same value on all strings*
#### Midi
- Full [MPE support](midi_implementation.md#mpe-implementation)
- Full 14bit control over all parameters and modulation ([NRPN](nrpn_implementation.md))
- [Midi Tuning Standard](midi_implementation.md#midi-tuning-standard) support for microtonal scales
- Global [pressure control](midi_implementation.md#receiving-pressure-and-modwheel-data) with the modwheel
- Sostenuto support ([CC66](midi_implementation.md#cc-lookup-table))
- A range of system settings which give users granular control over what to send and receive:
    - [Velocity/pressure balance](settings_menu.md#velocity-pressure-in-balance)
    - [Aftertouch type](settings_menu.md#aftertouch-type-voice-bend-range)
    - [Channel and voice bend range](settings_menu.md#channel-bend-range)
    - [Map Midi to scale](settings_menu.md#map-to-scale)
    - [Incoming clock multiplier](settings_menu.md#clock-multiplier)
    - [Filter clock, transport, CC, NRPN, LFO, Y/Z controller messages](settings_menu.md#filter)
    - [System Common messages 120-123](midi_implementation.md#channel-mode-messages)
    - [Soft thru](settings_menu.md#enable-soft-thru)
    - [Disable TRS midi out](settings_menu.md#enable-trs-out)
- New Settings Menu actions:
    - [Push preset parameters over midi](settings_menu.md#push-preset)
    - [Midi Panic](settings_menu.md#midi-panic)

Plinky now has perfect roundtrip-support for notes (pressure, pitch) and parameters. This means a performance on the Plinky can be recorded in a DAW and will sound exactly the same when playing it back on the Plinky, especially when using high resolution values. (Loss of accuracy due to the low resolution of Midi CCs sadly can't be accounted for.)

Consult the [Midi implementation](midi_implementation.md), [NRPN implementation](nrpn_implementation.md) and [Settings Menu](settings_menu.md) reference guides for more details.
#### CV
- Plinky now generates a new touch on a rising CV Gate, using the CV Pitch voltage as its pitch, as is common in eurorack
- When [CV quantize](settings_menu.md#cv-in-quantization) is active, the strength of the quantization can now be tweaked with the [P_MICROTONE] parameter
- The CV Gate can be configured as a binary input (Gate) or a continuous value (Pressure) in the [Settings Menu](settings_menu.md#gate-in-pressuregate)
- The PPQN for both incoming and outgoing clock can be configured in the [Settings Menu](settings_menu.md#clock-in-ppqn)
- CV Gate output is now a true binary +5V/0V gate (it previously generated a continuous voltage based on the max pressure)
- When playing an arp which plays one note at a time, the Pitch Lo CV output will continuously output the pitch of the lowest touched string (pedal tone) 
#### Playing Surface
Some small but important changes have been made to the playing surface:

 - A [P_ROOT] parameter has been added on the empty pad to the right of the [P_RELEASE1] pad. This allows for intuitive transposition with a range of 0 (C) to +11 (B) semitones
 - The value of the [P_DEGREE] parameter no longer affects the mapping of root LEDs on the pads. The bottom-left pad is now always lit up as a root note, making the layout more stable and easier to navigate
- In some cases, root notes on the higher strings are mapped in a way that is a clearer repetition of the root notes pattern on the lower strings
- There is now a [setting](settings_menu.md#global-pad-layout) which makes the pad layout persist across presets

#### Settings Menu
New options in the Settings Menu:

- [A4 reference pitch](settings_menu.md#a4-reference-pitch): 430-445Hz
- [Local control on/off](settings_menu.md#enable-local-control)

Find a full overview of all items in the Settings Menu in its [reference guide](settings_menu.md)

### Upgrades

#### Pitch restriction
- Internal pitch mapping now has a clearly defined valid range (C-1 through C7) and is well implemented within this range. This fixes a bunch of bugs where note names wouldn't show on screen, high/low touches would result in an incorrect pitch, or strings would even stop playing altogether
- Pitches outside the valid range are muted or rounded to fall within the valid range
- Pads outside the valid range show a dim led and do not produce sound at all

[INDENT=2]
##### Pitch overview
| Note name | Midi note | CV voltage | Frequency | Notes
|-|-|-|-|-|
| C-1 | 0 | -3V |8.18 Hz | Bottom Boundary |
| C2 | 36 | 0V |  65.41 Hz | CV Pitch Center |
| A4 | 69 | +2.75V | 440 Hz | [Reference Pitch](settings_menu.md#a4-reference-pitch) | 
| C7 | 96 | +5V |  2093 Hz | Top Boundary |

*Pitch CV in/outputs reach from just over +5V down to roughly -2.7V (inputs) or -3V (outputs)*
[/INDENT]

#### External gear
Internal and external touches (physical versus Midi/CV touches) are now processed in a much more centralized way. In practice this means internal and external signals are much easier to combine, especially when using additional external gear. For example:

- Triggering an internal envelope happens at the exact same frame as generating the Midi Note On message and turning CV Gate high
- Touch, Midi and CV all generate MPE Pitchbend values
- The internal pitch, outgoing Midi Note + Pitchbend and outgoing CV pitch are identical at all times (with one exception, see below)
- The [P_MICROTONE] parameter consistently defines the level of detuning for physical touches and quantized CV touches (Midi's detuning is defined by Midi Pitchbend)
- When controlling external gear with Plinky, there is a chance that pitch and glide modulation is better applied on the external device itself. For that reason, [P_PITCH] and [P_GLIDE] are ignored by default when generating MPE Pitchbend messages. Enabling MPE Fine Tuning in the [Settings Menu](settings_menu.md#filter-2) adds [P_PITCH] and [P_GLIDE] modulation back in. CV Pitch output always includes [P_PITCH] and [P_GLIDE] modulation

#### UI
- Clearing a preset or sequence in the Load UI now only clears the floating preset/sequence, without overwriting any of the preset/sequence slots. 
- When clearing a preset or sequence, it no longer matters which pad you press exactly. Holding [FN_CLEAR] plus any preset pad will clear the floating preset, holding [FN_CLEAR] plus any sequence pad will clear the floating sequence
- Loading a sample now happens instantly
- If no changes have been made to the currently loaded Preset/Sequence, loading a new Preset/Sequence now happens instantly
- The A/B knobs now have a small deadzone in the center, making it easier to set them to exactly zero
- Non-synth presses, especially on function-pads, have had responsiveness issues since the Loopop review. The noise filtering process for non-synth presses has been refined to both be more responsive and have identical responsiveness on all pads
- A `#` sign has been added. Yes, you read that right: we have an actual sharp sign now!
- Small cleanups in the layout of the Settings Menu

#### Various
- The "Max Pressure" mod source, meter on screen and CV output now follow Envelope 1
- CV Gate is how high during the CV calibration process, making it easier to tune with a eurorack oscillator
- Midi out over USB is no longer throttled
- Removed yet another source of undesired pitch sliding at the start of new notes
- Generally a bunch of work has been done on making code more efficient and organized

### Fixes
- The [P_SYN_LVL], [P_SYN_WET_DRY], [P_IN_LVL] and [P_IN_WET_DRY] parameters now work as expected. Previously there were several undesired interactions between the Synth Level parameter and how the external signal and effects were mixed
- The scope now always shows the correct amplitude of the outgoing audio
